## 🔧 技术实现

### 核心特性
1. **自动检测**: 首次访问时从 localStorage 读取语言偏好
2. **即时切换**: 点击按钮立即更新所有文本
3. **持久化**: 语言选择自动保存到 localStorage
4. **事件驱动**: 语言变更触发自定义事件
5. **灵活扩展**: 易于添加新语言和翻译键

### API 使用

#### HTML 标记
```html
<!-- 文本内容 -->
<h1 data-i18n="app.title">Copy Trade Bot</h1>

<!-- 按钮 -->
<button data-i18n="app.save">保存</button>

<!-- 输入框 placeholder -->
<input data-i18n-placeholder="wallet.address">

<!-- 提示文本 -->
<small data-i18n="form.hint">提示文本</small>
```

#### JavaScript 调用
```javascript
// 获取翻译
const text = i18n.t('app.title');

// 设置语言
i18n.setLang('en');

// 获取当前语言
const lang = i18n.getCurrentLang();

// 监听语言变更
window.addEventListener('languageChanged', (e) => {
    console.log('Language:', e.detail.lang);
});
```

## 📞 技术支持

### 常见问题

**Q: 如何添加新语言？**
A: 在 `i18n.js` 的 `translations` 对象中添加新语言配置，然后在语言切换按钮中添加对应选项。

**Q: 如何添加新的翻译键？**
A: 在 `i18n.js` 的中英文配置中同时添加新键值对。

**Q: 语言切换不生效怎么办？**
A: 检查浏览器控制台是否有错误，确认 `i18n.js` 已正确引入，清除浏览器缓存后重试。

**Q: 如何自定义语言切换按钮样式？**
A: 修改 HTML 中的 `.language-switcher` 相关 CSS 样式。
