# 钱包私钥导入功能使用指南

## 功能概述

copy-trade-bot项目现已支持从前端页面直接导入和删除钱包私钥，无需手动编辑配置文件。

## 新功能特性

### 1. 私钥导入
- **支持格式**：64位十六进制私钥、12/24个单词的助记词
- **安全存储**：私钥加密存储在Redis中
- **自动地址生成**：从私钥自动生成对应的Solana地址
- **实时验证**：前端实时验证私钥格式和有效性

### 2. 双模式导入
- **地址导入**：仅添加监控地址，不导入私钥
- **私钥导入**：完整导入私钥，支持自动交易执行

### 3. 安全管理
- **权限控制**：需要登录认证才能操作
- **私钥隐藏**：前端不显示完整私钥信息
- **安全提醒**：导入时显示安全警告信息

## 使用步骤

### 1. 访问钱包管理页面
1. 登录Web管理界面
2. 点击顶部导航栏的"钱包管理"
3. 点击"添加钱包"按钮

### 2. 选择导入方式
在弹出的模态框中，选择标签页：
- **地址导入**：输入钱包地址进行监控
- **私钥导入**：输入私钥或助记词进行完整导入

### 3. 私钥导入流程
1. 选择"私钥导入"标签页
2. 输入私钥或助记词（支持64位十六进制或助记词格式）
3. 设置钱包名称和交易参数
4. 点击"导入私钥"按钮
5. 系统将自动验证并导入钱包

### 4. 删除钱包
1. 在钱包列表中选择要删除的钱包
2. 点击"删除钱包"按钮
3. 确认删除操作

## API接口

### 导入私钥钱包
```
POST /api/wallets/import-private-key
Content-Type: application/json
Authorization: Bearer {token}

{
  "private_key": "your_private_key_or_mnemonic",
  "name": "钱包名称",
  "type": "high_frequency",
  "take_profit_pct": 100,
  "stop_loss_pct": 10,
  "enabled": true,
  "follow_sell": true
}
```

### 获取私钥钱包列表
```
GET /api/wallets/private-keys
Authorization: Bearer {token}
```

### 删除私钥钱包
```
DELETE /api/wallets/private-key/{address}
Authorization: Bearer {token}
```

## 安全注意事项

1. **网络环境**：确保在安全的网络环境下操作
2. **私钥保护**：私钥存储在服务器端，确保服务器安全
3. **访问控制**：限制Web管理界面的访问权限
4. **备份重要**：建议备份重要私钥到安全位置

## 技术实现

### 前端技术
- Bootstrap 5 UI框架
- 标签页切换显示不同导入模式
- 实时输入验证和错误提示
- 加载状态显示

### 后端技术
- Go语言实现
- Redis存储私钥和钱包配置
- 助记词和私钥格式验证
- 地址自动生成

## 故障排除

### 常见问题
1. **私钥格式错误**：检查是否为64位十六进制或有效助记词
2. **地址已存在**：钱包地址已存在，请检查列表
3. **网络错误**：检查网络连接和Redis服务状态

### 日志查看
查看应用日志获取详细错误信息：
```bash
tail -f logs/copytrade.log
```
